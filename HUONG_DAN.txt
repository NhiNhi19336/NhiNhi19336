ĐƯA "HÌNH KHỐI 3D" LÊN CH PLAY - CHỈ NỘP FILE .AAB (không APK, không zip)

CÁCH A: không cần cài gì, dựng .aab ngay trên GitHub
 1) Tạo repo GitHub ở chế độ Private, tải toàn bộ nội dung thư mục này lên (giữ thư mục .github).
 2) Tab Actions > "Tạo keystore (chạy 1 lần)" > Run workflow > nhập mật khẩu.
    Xong tải artifact "keystore" về máy, CẤT KỸ upload.jks (mất là không cập nhật app được).
 3) Settings > Secrets and variables > Actions > New repository secret:
    KEYSTORE_BASE64 = nội dung file upload.jks.b64
    KEYSTORE_PASSWORD = mật khẩu đã nhập ở bước 2
 4) Actions > "Build signed AAB" > Run workflow. Xong tải artifact "hinhkhoi3d-aab": trong đó là file .aab.
 5) Xóa artifact keystore trên GitHub sau khi đã cất bản của bạn.
 (Workflow chưa được chạy thử trong môi trường của tôi; nếu lỗi, copy log gửi lại để sửa.)

CÁCH B: Android Studio
 npm i @capacitor/core @capacitor/android && npm i -D @capacitor/cli @capacitor/assets
 npx cap add android && npx capacitor-assets generate --android && npx cap sync android && npx cap open android
 Build > Generate Signed App Bundle > Android App Bundle (.aab). Mỗi lần nộp bản mới phải tăng versionCode.

PLAY CONSOLE
 - Tạo app > tải .aab lên.
 - Icon 512: store/icon-512.png | Ảnh bìa 1024x500: store/feature-1024x500.png | Ảnh chụp màn hình: tự chụp (tối thiểu 2).
 - Chính sách riêng tư: sửa email trong store/privacy.html, đăng lên GitHub Pages/Netlify, dán link.
 - App có trẻ em: khai báo theo chính sách Families. Data safety: không thu thập dữ liệu. Quảng cáo: không.
 - Tài khoản mới có thể phải chạy kiểm thử kín trước khi lên Production: xem yêu cầu hiện hành trong Play Console.
 Sửa game: sửa www/index.html rồi chạy lại workflow Build.
